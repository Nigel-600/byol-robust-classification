# Seed Quality Classification

Binary image classification pipeline (Good Seed / Bad Seed) using supervised ResNet-50 baselines and a self-supervised BYOL pre-training stage.

---

## Overview

This project trains and evaluates convolutional neural network models to classify seeds as **good** or **bad** from RGB images. Two paradigms are explored:

1. **Supervised baseline** — several ResNet-50 variants fine-tuned directly on labelled data.
2. **Self-supervised pre-training (BYOL)** — a Bootstrap Your Own Latent encoder pre-trained without labels, then adapted via linear probing or full fine-tuning.

Gradient-weighted class activation maps (GradCAM / EigenCAM) are used throughout for qualitative interpretability. K-Means clustering on learned embeddings provides an additional unsupervised evaluation across all three data batches.

## Models

### Supervised Baselines

All variants use a ResNet-50 backbone with ImageNet pre-trained weights (except the `none_weights` ablation).

| Model name | Backbone | Head | Training strategy |
|---|---|---|---|
| `resnet50` | ResNet-50 | Single linear layer | Full fine-tune |
| `resnet50_mlp` | ResNet-50 | MLP head | Full fine-tune |
| `resnet50_ffe` | ResNet-50 | Single linear layer | Frozen encoder (feature extraction) |
| `resnet50_mlp_ffe` | ResNet-50 | MLP head | Frozen encoder (feature extraction) |

All models output 2 logits (binary classification) and are trained with cross-entropy loss, SGD with momentum 0.9, and a StepLR scheduler.

### BYOL (Self-Supervised)

The BYOL implementation follows the Bootstrap Your Own Latent framework:

- **Online network** — ResNet-50 encoder + MLP projector + MLP predictor
- **Target network** — ResNet-50 encoder + MLP projector (exponential moving average of online weights)
- **Loss** — Normalised MSE between online predictions and target projections
- **Augmentation** — Random crop, colour jitter, grayscale, Gaussian blur, horizontal flip, normalisation (two views per image)

The encoder is pre-trained for 100 epochs on the unlabelled training images, then the frozen weights are used in two ways:

- **Linear probe** (`seed_clf_probed`) — encoder frozen, only the classification head is trained.
- **Fine-tuned** (`seed_clf`) — full network fine-tuned end-to-end starting from the BYOL encoder.

## Usage

Open and run `main.ipynb` sequentially. The notebook is self-contained and follows this order:

1. **Setup** — imports, seed fixing, dataset discovery.
2. **Data loading** — CSV manifest generation, `ImageCSVDataset`, augmentation pipelines, stratified train/val split.
3. **Baseline training** — four ResNet-50 variants trained and checkpointed under `ckpts/`.
4. **Baseline evaluation** — accuracy, precision, recall, F1, AUC, confusion matrices on Batch 1 test set.
5. **Cross-batch evaluation** — models evaluated on Batch 2 and Batch 3 (with bounding-box crop parsing for Batch 3).
6. **GradCAM / EigenCAM** — visualisation of true/false positive/negative cases.
7. **Embedding analysis** — ResNet-50 features extracted and clustered with K-Means; ARI and NMI reported.
8. **BYOL pre-training** — self-supervised encoder trained for 100 epochs.
9. **BYOL fine-tuning & linear probing** — two classifiers built on top of the BYOL encoder and evaluated on all three batches.
10. **Comparative analysis** — training histories plotted, clustering scores compared across methods.

Checkpoints are saved to `ckpts/` and final model weights to `models/`. The notebook skips re-training if a saved model already exists at the expected path.

## Reproducibility

A global seed of `42` is applied to `torch`, `numpy`, and `random` at startup. DataLoader workers are also seeded for deterministic behaviour.

## Evaluation Metrics

The following metrics are computed on each test set: **Accuracy**, **Precision**, **Recall**, **F1 Score**, **AUC-ROC**, and **Confusion Matrix**. Embedding quality is additionally assessed via **Adjusted Rand Index (ARI)** from K-Means clustering, with 2 clusters.
